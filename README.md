## 🚀 Хэрэгжүүлэлт — одоо юу ажилладаг вэ

Доорх хэсгүүд бол **анхны санаа, спецификаци**. Харин эдгээр файлууд дээр үндэслэн жинхэнэ ажилладаг MVP **аль хэдийн бичигдсэн**:

| Хуудас | Файл | Юу хийдэг вэ |
|---|---|---|
| 🏠 Нүүр | `index.html` | Hero, "Хэрхэн ажилладаг вэ", жишээ тестийн загварууд |
| 📝 Тест үүсгэх | `create.html` | 4 алхамт visard: нэр → асуулт сонгох/нэмэх → зөв хариулт тохируулах → линк авах |
| 🎮 Тест бөглөх | `play.html?code=XXXXXX` | Найзын нэр/аватар сонгоод, нэг дэлгэцэд нэг асуулт, progress bar |
| 🏆 Үр дүн | `result.html?code=&attempt=` | Оноо, confetti, хариултын задаргаа, ranking |
| 🔐 Удирдлага | `manage.html?code=&token=` | Эзэмшигчийн admin token-той хуудас — линк хаах, ranking нуух, устгах |
| 📋 Миний тестүүд | `mine.html` | Энэ төхөөрөмж дээр үүсгэсэн бүх тестийн жагсаалт |
| 💞 Таарал тест | `match.html?code=XXXXXX` | Хоёр хүн тус бүрдээ (зөв хариулт байхгүй) хариулж, хариултууд хэр таарч байгааг (%) харьцуулдаг горим — Найзын/Хайрын 2 категори |

**Технологи:** Цэвэр HTML + [Tailwind CSS (Play CDN)](https://tailwindcss.com) + vanilla JavaScript. Build алхам (npm, bundler) шаардахгүй — шууд static file хост дээр ажиллана.

```
js/
├── theme.js        — Tailwind-ийн дизайны токенууд (өнгө, хэмжээ, фонт)
├── questions.js    — Асуултын сан (категориор) + Match горимын асуултууд (MATCH_QUESTION_BANK)
├── db.js           — Өгөгдлийн давхарга: localStorage + сонголтоор Firebase
├── ui.js           — Нийтлэг туслах функцууд (toast, share, avatar)
├── identity.js     — Нэгдсэн nickname+avatar профайл (бүх хуудсанд нийтлэг)
├── notifications.js — Эзэмшигчид шинэ хариулт/таарал ирсэн мэдэгдэл
├── firebase-config.js — Firebase тохиргоо (анхдагчаар унтраалттай)
└── create.js / play.js / result.js / manage.js / match.js — Хуудас тус бүрийн логик
```

### ▶️ Локал ажиллуулах

Браузер `fetch`/Clipboard/Share API-г зөв ажиллуулахын тулд `file://`-ээр биш, жижиг local сервертэй нээнэ:

```bash
python -m http.server 8080
# эсвэл
npx serve .
```

Дараа нь `http://localhost:8080/index.html` нээнэ.

### 🗄️ Өгөгдөл хадгалалт

Анхдагчаар бүх тест, хариулт **энэ төхөөрөмжийн `localStorage`**-д хадгалагдаж, **7 хоногийн дараа автоматаар устгагдана**. Энэ нь хурдан, бүртгэлгүй эхлэхэд тохиромжтой — гэхдээ найз өөр төхөөрөмж дээр линкийг нээвэл тухайн төхөөрөмж дээрээ л харагдана.

✅ **Firebase Realtime Database идэвхжсэн байгаа** (`js/firebase-config.js`, project: `emonos-c9418`) — тиймээс найзууд өөр өөр утас, өөр browser-оос ч тест бөглөж, эзэмшигч нь үр дүнг нь шууд харна. Хэрэв `ENABLED: false` болговол апп зөвхөн тухайн browser-ийн localStorage дээр ажиллах болно (найз өөр төхөөрөмжөөс орвол "Тест олдсонгүй" гэж харагдана).

## 🎮 Үндсэн функцүүд

### 1️⃣ Намайг хэр сайн мэдэх вэ? 💗 *(Core функц)*

Хэрэглэгч өөрийн тестийг үүсгэж, найзууд нь таах тоглоом.

- 5–20 асуулт сонгоно (бэлэн сан + өөрийн асуулт нэмэх)
- Асуулт бүрт өөрийн зөв хариултыг сонгоно
- Линк үүсгээд найзууддаа илгээнэ
- Найзууд хариулж, оноо авна
- Эзэмшигч бүх хариулагчдын оноог харна

**Асуултын жишээ:**
```
🍜 Миний хамгийн дуртай хоол юу вэ?
🎵 Би одоо ямар дуу давтаж сонсож байна вэ?
😴 Би өглөө хэдэн цагт сэрдэг вэ?
🌍 Би хаашаа очихыг хамгийн их мөрөөддөг вэ?
🙈 Миний хамгийн эвгүй дурсамж юу вэ?
```

### 2️⃣ Миний personality ямар вэ? ✨

Хөгжилтэй, хөнгөн, хуваалцахад зориулсан personality тестүүд.

| Тест | Үр дүнгийн жишээ |
|---|---|
| 🫂 Чи ямар төрлийн найз вэ? | "Групп чатын сүнс", "Нууцыг хадгалагч", "Хоолны төлөвлөгч" |
| 🌟 Чиний нууц авьяас юу вэ? | "Ухаалаг шийдэгч", "Төрөлхийн жүжигчин" |
| 🎨 Чи ямар aesthetic вэ? | "Soft girl/boy", "Dark academia", "Y2K", "Cozy" |
| 🧋 Чи ямар ундаа вэ? | Сүүтэй цай, Boba, Эспрессо... |

### 3️⃣ Нууцхан асуулт 💌

Найзууд бие биедээ **эерэг, хөгжилтэй** асуулт илгээх хэсэг.

- Нэрээ нууцалж асуулт илгээх боломжтой
- Хүлээн авагч хариулах эсэхээ өөрөө шийднэ
- ⚠️ **Moderation заавал байна** — доромжлол, дээрэлхэлтийг шүүнэ
- Report болон block товч бүх газар байна

### 4️⃣ Bestie ranking 🏆

| Цол | Тайлбар |
|---|---|
| 👑 Хамгийн сайн мэддэг | Хамгийн өндөр оноотой найз |
| ⚡ Хамгийн хурдан | Хамгийн түргэн хариулсан найз |
| 🎯 Нарийн мэргэн буудагч | Хамгийн олон зөв хариулсан найз |
| 🤪 Хамгийн их андуурсан | Хөгжилтэй "хамгийн сул" цол (эерэг өнгө аясаар) |

Ranking-ийг story-д хуваалцах card болгон гаргана.

| 🍪 Tracking | Хамгийн бага. Гуравдагч талын зар сурталчилгааны tracker хэрэглэхгүй |

### Moderation ба хамгаалалт

- 🚫 **Автомат шүүлтүүр** — доромжилсон үг, хараалын үгийн жагсаалт (Монгол + англи + латинаар бичсэн монгол)
- 🚩 **Report товч** — асуулт, хариулт, тест бүр дээр
- 🛑 **Block** — тодорхой хүнийг блоклох
- 👀 **Хүний шалгалт** — report ирсэн контентыг шалгах
- 🧒 **Насны хамгаалалт** — насанд хүрээгүй хэрэглэгчийн мэдээллийг онцгой хамгаална, нууцхан асуултыг хязгаарлана
- ⏱️ **Rate limit** — spam, bot-оос сэргийлнэ
- 💬 **Эерэг өнгө аяс** — асуултын сан нь зөвхөн эерэг, хөгжилтэй асуулттай
